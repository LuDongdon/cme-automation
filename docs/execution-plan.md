# 继续教育自动化工具 — 执行步骤

## 总体原则

1. **一次只做一个阶段**，完成并验证后再进入下一阶段
2. **每个阶段包含：编码 → 测试 → 记录 → 提交**
3. **遇到问题先记录到 devlog，不要在不清楚的情况下猜测**
4. **每个阶段完成后更新本文档的状态**
