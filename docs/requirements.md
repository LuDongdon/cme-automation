# 继续教育自动化工具 — 需求文档

## 项目目标

自动化操作继续教育网站 `https://your-cme-platform.example.com/index.html`，完成课程创建和扫码考勤两大功能。

## 功能需求

### F1: 登录认证

1. 打开网站登录页面
2. Edge 浏览器自动填充密码
3. 点击登录按钮
4. 处理安全手机验证弹窗
   - 选择验证码接收人：接收人 A 或 接收人 B（在 config.yaml 中配置）
   - 用户手动输入验证码
5. 等待进入主操作页面

### F2: 课程创建

**F2.1 添加活动**
- 左侧栏选择「院内活动管理」→「科室院内活动」
- 点击「新增」按钮
- 填写活动表单：

| 字段 | 默认值 |
|------|--------|
| 办年度 | 2026 |
| 学分分类 | 有组织的继续医学教育实践活动 → 单位组织的继续医学教育实践活动 |
| 活动内容 | 专业课 |
| 所属医学体系 | 西医 |
| 拟授分人数 | 5 |
| 学科 | 临床外科学 |
| 三级学科 | 整形外科学 |
| 活动名称 | (用户输入) |
| 活动形式 | 研讨会 |
| 考核方式 | 其他 |
| 学分 | 0.2 |

- 点击「下一步完善举办周期」

**F2.2 举办周期**
- 点击「添加举办周期」
- 设置举办开始日期+时间、举办结束日期+时间
- 日期模式支持：每天/周一三五/周二四六/仅周末/自定义

**F2.3 添加课程**
- 点击「添加课程」
- 填写：
  - 开始时间 / 结束时间（同举办周期）
  - 讲授题目（同活动名称）
  - 时长：1
  - 是否主讲人授分：是

**F2.4 添加教师**
- 点击「添加教师」
- 证件号：000000000000000000（18 位，在 config.yaml 的 course.teachers 中配置）
- 姓名：张三

**F2.5 返回列表**

### F3: 扫码考勤

**F3.1 签到流程**
1. 在课程列表中找到目标课程
2. 点击「扫码考勤」
3. 点击「开始考勤」
4. 考勤配置保持默认，点击「确定」
5. 二维码时效选择「300秒」
6. 截图二维码弹窗并发送到微信群
7. 每300秒刷新一次，共发送3张二维码截图
8. 关闭二维码弹窗（点X）

**F3.2 签退流程**
- 等待到签退时间（默认20:45）
- 重复 F3.1 步骤1-7

### F4: 微信发送

- 自动将截图发送到用户指定的微信群
- 三级回退策略：
  1. CDP 连接控制微信
  2. pywinauto UIA 自动化
  3. 保存截图到本地，弹窗提醒手动发送

### F5: Web UI

- 本地 Web 界面用于参数配置和操作触发
- 实时日志显示
- 考勤状态监控
- 二维码预览

## 配置项

- 所有时间可配置
- 微信目标群可配置
- 验证码接收人可配置
- 二维码时效和发送次数可配置
- 支持批量创建多个课程
